# نظام السراكي — حزمة الربط بـ Lovable

## ما في هذه الحزمة

| المسار | المحتوى |
| --- | --- |
| `LOVABLE-PROMPT.md` | المواصفات الكاملة — الصقها في Lovable كأول رسالة |
| `src/` | المشروع المصدري جاهز للتشغيل (Vite + React + TS + Tailwind) |
| `public/seed.json` | كل البيانات الحالية (12,830 عاملًا، 667 سركى، 195 مهنة، 98 مشروعًا) |
| `supabase/schema.sql` | مخطط قاعدة البيانات كاملًا + الصلاحيات + view التسوية |
| `supabase/seed/*.csv` | البيانات جاهزة للاستيراد إلى Supabase |

## خطوات الربط

### ١ — ارفع الحزمة على GitHub
```bash
cd lovable
git init && git add -A
git commit -m "نظام السراكي — الشروق للمقاولات"
git branch -M main
git remote add origin https://github.com/<حسابك>/shorouk-sarak.git
git push -u origin main
```

### ٢ — اربطه بـ Lovable
في Lovable: **New Project → Import from GitHub** واختر المستودع. سيقرأ Lovable المشروع كما هو ويعرضه فورًا.

### ٣ — وجّه Lovable
الصق محتوى `LOVABLE-PROMPT.md` في أول رسالة حتى يعرف قواعد العمل والهوية ولا يعيد اختراعها.

### ٤ — شغّله محليًا للتأكد
```bash
npm install
npm run dev
```
يفتح على `http://localhost:8080`. البيانات تُحمّل من `public/seed.json` مرة واحدة ثم تُخزَّن في IndexedDB، فيعمل بلا إنترنت.

## التحول إلى قاعدة بيانات حقيقية (لاحقًا)
1. أنشئ مشروع Supabase من داخل Lovable (زر Supabase).
2. شغّل `supabase/schema.sql` في SQL Editor.
3. استورد ملفات `supabase/seed/` بالترتيب المذكور في `supabase/seed/README.md`.
4. املأ `.env` من `.env.example` واضبط `VITE_USE_SUPABASE=true`.

طبقة الوصول معزولة في `src/lib/storage.ts` و`src/lib/supabaseRepo.ts` — التحويل لا يمسّ الشاشات.
