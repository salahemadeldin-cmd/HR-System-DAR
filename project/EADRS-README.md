## نموذج التكويد

### كود المشروع
ثلاثة أرقام، من 100 إلى 197، حسب القائمة الرسمية المعتمدة (98 مشروعًا).

### كود المقاول
ثمانية أرقام: `PPP` كود المشروع + `NN` تسلسل المقاول داخل المشروع + `000`.

```
18416000  →  مشروع 184 · المقاول رقم 16
16218000  →  مشروع 162 · المقاول رقم 18
```

### كود العامل — تلقائى بالكامل

يُولَّد آليًا ولا يُدخل يدويًا، بترتيب إلزامى فى شاشة "إضافة عامل":

```
القطاع  →  المشروع  →  المقاول  →  كود العامل (تلقائى)
```

**عمالة مقاولى الباطن:** الكود يأخذ بادئة كود المقاول (٥ أرقام) ويكمل آخر كود مسجَّل تحت نفس المقاول.

```
مقاول 18416000 · آخر عامل 18416027  →  الكود الجديد 18416028
```

**العمالة الذاتية:** الكود يُشتق من كود المشروع.

```
كود المشروع + 10 + تسلسل    مثال: مشروع 162  →  16210133
```

قواعد الحماية:
- حقل الكود للقراءة فقط، غير قابل للتعديل.
- زر الحفظ معطَّل حتى يوجد كود مُولَّد + مشروع + مقاول + اسم.
- لا يُحفظ أى عامل بكود خالٍ.

## الاستيراد من ملفات Excel

| الملف | الورقة | الحقول المستخدمة |
|---|---|---|
| اكواد المشاريع.xlsx | `Sheet1` | كود المشروع · اسم المشروع |
| العمالة الذاتى.xlsx | `Main` | الكود · الاسم · رقم البطاقة · المهنة · الإدارة · المشروع · مدير القطاع · تاريخ استلام العمل |
| العمالة الذاتى.xlsx | `Sheet8` | المهن · كود المهنة · الإدارة |
| العمالة الذاتى.xlsx | `المنحة` | رقم البطاقة · الفئة · البدل |
| مقاولين العمالة.xlsx | `Sheet1` | WorID · WorName · WorIDCard · DefJob · كود المقاول · اسم المقاول · المشروع |
| Sector and Projects.xlsx | `Sheet1` | الموقع · كود الموقع · القطاع الجغرافى · كود القطاع |

قواعد المعالجة:
- تواريخ Excel الرقمية تُحوَّل إلى `dd/mm/yyyy`.
- أسماء المشاريع المختصرة تُطابَق بأكواد المشاريع الرسمية (تطبيع الألف/الياء/التاء + مطابقة جزئية + جدول مرادفات).
- لاحقة فئة الأجر فى المهنة (`عامل مخزن A`) تُفصل إلى مهنة + فئة.
- البدل وقيمة الفئة يُربطان برقم البطاقة من ورقة "المنحة".

## المؤشرات والحسابات

| المؤشر | المعادلة |
|---|---|
| نسبة الحضور اليوم | الحاضرون ÷ المشمولون بأجهزة البصمة |
| ساعات العمل اليومية | آخر بصمة خروج − أول بصمة دخول |
| الساعات الإضافية | مجموع (ساعات العمل − 8) للساعات الزائدة فقط |
| تكلفة العمالة | مجموع (ساعات العمل × أجر ساعة المهنة) |
| أجر الساعة | قيمة الفئة ÷ ساعات العمل المتعاقد عليها |
| نسبة المطابقة الآلية | السراكى المطابقة ÷ إجمالى السراكى |
| التغطية | المشمولون بالبصمة ÷ إجمالى القوة المسجلة |

كل المؤشرات محسوبة من البيانات الفعلية؛ وتظهر `—` عند غياب سجل البصمة (لا قيم افتراضية).

### فئات الأجر

| الفئة | الوصف |
|---|---|
| A | إشراف |
| B | فنى / صنايعى |
| C | مساعد |
| D | عمالة عادية |
| E | تحت التدريب |

قيمة الفئة والبدل قابلتان للتعديل لكل عامل مع حفظ صريح (مسودة لكل صف + زر حفظ/تراجع + شريط حفظ جماعى).

## التشغيل

**النسخة المستقلة:** افتح `نظام تسجيل الحضور والانصراف - نسخة مستقلة.html` فى أى متصفح — ملف واحد يضم القاعدة والشعار والأنماط، ويعمل بدون إنترنت.

**نسخة التطوير:**

```
EADRS-Prototype.dc.html          ← النظام
data/eadrs-data.json             ← قاعدة البيانات
data/sector-sites.json           ← سجل القطاعات والمواقع
data/project-registry.json       ← سجل المشاريع الرسمى
brand-logo.png                   ← الشعار
_ds/                             ← أنماط وهوية الواجهة
backup/                          ← نسخ احتياطية
```

## خارطة التطوير

1. ربط أجهزة البصمة وتغذية `attendance` آليًا.
2. تكويد الجهات الثلاث غير المُكوَّدة (198 / 199 / 200 أو ضمها لمشاريع قائمة).
3. المطابقة الآلية للسراكى مع سجل البصمة عند توفر الحركات.
4. تقارير التكلفة الشهرية لكل مشروع ومقاول.
5. تصدير التقارير Excel / PDF.
6. تسجيل الدخول والصلاحيات على مستوى الخادم.
